## 2024-04-16 - Missing Admin Authorization on Master Whiskey Data
**Vulnerability:** Any authenticated user could create, edit, or delete entries in the master `Whiskey` global directory because `Create.cshtml.cs`, `Edit.cshtml.cs`, and `Delete.cshtml.cs` under `Pages/Whiskies` lacked authorization attributes. Only the `/Admin` folder was protected by convention.
**Learning:** Razor Pages convention-based folder authorization (`AuthorizeFolder("/Admin")`) does not automatically protect administrative-level entities that reside outside the designated admin folder.
**Prevention:** Always explicitly annotate page models with `[Authorize(Roles = "Admin")]` for global entity modification pages, regardless of folder structure.
## 2024-06-22 - [CRITICAL] SSRF and Path Traversal in Image Uploads
**Vulnerability:** Server-Side Request Forgery (SSRF) and Path Traversal vulnerabilities found in `Create.cshtml.cs` and `Edit.cshtml.cs`. The application fetched images from user-supplied URLs without verifying the host or protocol, and appended user-supplied filenames to GUIDs during local uploads without stripping directory paths.
**Learning:** Even when using `Guid.NewGuid()`, appending the original `FileName` can lead to path traversal if the filename contains path separators. `HttpClient` defaults to following redirects, which can bypass initial URL validation in SSRF attacks.
**Prevention:** Always validate user-supplied URLs against an allowlist of trusted domains, enforce HTTPS, and disable auto-redirects on `HttpClient` (`AllowAutoRedirect = false`). For file uploads, use `Path.GetExtension(fileName)` instead of appending the entire original filename.
